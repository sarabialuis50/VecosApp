# 🌐 Menu.IA - Frontend (Client App)

Esta es la aplicación cliente de MenuPro, construida con React para ofrecer una experiencia rápida, moderna y responsiva a los usuarios y administradores de restaurantes.

## 🚀 Características del Frontend

- **Interfaz Intuitiva:** Construida con Tailwind CSS y componentes de Shadcn UI para una estética premium.
- **PWA Ready:** Configurada para funcionar como una aplicación web progresiva.
- **Real-time UI:** Actualización instantánea de pedidos y estados de mesa mediante integración con WebSockets.
- **Gestión Visual:** Paneles dedicados para Cocina, Meseros y Dueños.

## 🛠️ Tecnologías Utilizadas

- **React.js** (v18+)
- **Tailwind CSS** para estilos.
- **Lucide React** para iconografía.
- **Framer Motion** para animaciones fluidas.
- **Axios** para comunicación con la API.

## ⚙️ Configuración

Asegúrate de configurar la URL base de la API en tus variables de entorno si es necesario (usualmente en un archivo `.env` en la raíz de esta carpeta).

## 🏁 Inicio Rápido

1. Instalar dependencias:
   ```bash
   npm install
   ```

2. Iniciar servidor de desarrollo:
   ```bash
   npm run start
   ```

3. Construir para producción:
   ```bash
   npm run build
   ```
